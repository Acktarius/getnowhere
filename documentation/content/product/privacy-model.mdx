This page is a public privacy overview. It is not a threat-model dump and not
a guarantee of anonymity.

## Two different paths

Get NowHere uses more than one delivery path. They excel in different ways.

**Relationship signaling and relay** ride the Conceal Network blockchain
(smart messages, ChaCha12). Outsiders without the relevant view keys do not
read message bodies. The counterparty learns the message by design. This
path does **not** give the counterparty your IP address the way a direct
connection does.

**Live peer-to-peer** means no chat server: two peers, hole-punched if
needed, sealed with **ChaCha20-Poly1305**. The invited peer can still learn
your IP address and port. Network observers can still see that traffic
exists. That is ordinary direct connectivity, not anonymous routing.

## What is not claimed

- Get NowHere is **not** an anonymity network.
- Live chat is **not** documented as metadata-complete.
- Tor, VPN leak preflight, and relay-only live transport are **not
  implemented**. Treat them as future work if they appear in internal notes.
- Publishing this page is not a promise that every host already matches every
  privacy property.

## Practical reading

If you need to avoid showing your IP to a chat counterparty, a live direct
session is the wrong mental model. The Conceal-backed path avoids that
particular disclosure; it costs latency and still leaves public-chain
activity residues such as transaction existence and rough timing.
