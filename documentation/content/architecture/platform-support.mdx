title: Platform support
description: Linux, Windows, and Android today. iOS in process. No macOS package yet.
---

How to get a build: [getting started](/getting-started).

| Platform | Status | What you install |
| --- | --- | --- |
| Linux | Available | AppImage, `.deb`, or zip from a desktop GitHub release |
| Windows | Available | Zip — run `getnowhere.exe` |
| Android | Available | APK from a GitHub release whose tag includes **F-Droid** |
| iOS | In process | Not a public store build yet. Open a GitHub issue to join the beta |
| macOS | Not packaged | No desktop download yet |

Linux and Windows are the same desktop app: Conceal wallet, QR contacts,
rooms. Android is the same product as an APK with notifications and
background services.

There is no phone number, no email, and no account signup on any of these.
You need a Conceal wallet — and another person with Get NowHere.
