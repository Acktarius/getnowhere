Public documentation site

Add a separate public docs website and publish it on GitHub Pages. The existing internal docs/ folder stays private.

What you will get

  • A Fumadocs site you can run locally at http://localhost:3000/.
  • Curated public pages under documentation/content/.
  • A GitHub Pages deploy at https://acktarius.github.io/getnowhere/ after Pages is set to GitHub Actions.

What will not change

  • The Vite app, Electron packaging, mobile wrapper, sidecar, Android workflow, and Electron release workflow.
  • Internal engineering docs will not be copied or published automatically.

After merge

  1. Repository Settings → Pages → Source = GitHub Actions.
  2. Merge to main or run the workflow manually.
  3. Open the Pages URL and check navigation, assets, and refresh on nested pages.
