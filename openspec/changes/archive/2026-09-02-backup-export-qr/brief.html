Backup export QR

TL;DR

Settings → Backup gets a third action: Show export QR code. After you enter the wallet password, a modal shows a QR another device can scan to import this wallet (keys + creation height). Same Got it / Need more time timing as Reveal seed & keys.

What you'll get

  • A Show export QR code button right after Reveal seed & keys (QR icon).
  • Password required — same as reveal and download.
  • A modal that shows only the export QR (no extra warning text).
  • Got it closes it; Need more time works the same as the seed dialog (30s, then 5s grace).
  • The QR encodes address, spend key, view key, and wallet creation height so import can skip scanning from genesis.

How it works

You type the wallet password and tap the new button. The app unlocks the same secrets used for reveal, builds the Conceal-style wallet QR string, and shows it. Closing the modal clears the password and the QR, same as closing reveal. 

flowchart TD
  A[Backup settings] --> B[Enter wallet password]
  B --> C[Show export QR code]
  C --> D{Password OK?}
  D -->|no| E[Show error — stay on Backup]
  D -->|yes| F[Modal: export QR]
  F --> G[Got it]
  F --> H[Need more time]
  F --> I[Auto-close after grace]
  G --> J[Clear password and QR]
  I --> J

What changes for you

  • On Settings → Backup, a new button between Reveal and Download.
  • Settings Backup subtitle will mention export QR.
  • Reveal and Download stay as they are.

Risks and open questions

  • The QR holds spend/view keys — treat it like showing the seed. Don’t screenshot it in public.
  • Very old wallets without a stored creation height encode height 0 (import starts from genesis).
  • View-only wallets are not supported (error if that path is hit).

Out of scope

  • View-only export QR.
  • PDF or file that embeds the QR.
  • Warning / disclaimer text in the modal.
  • Changes to how import scans a QR.
