Mobile app access and data unlock

TL;DR

On Android and iOS, Get NowHere gets two separate locks: app access (blur the UI when you switch away — wallet stays open) and data unlock (open the wallet with fingerprint/face or password). Crypto stays in native code; web and desktop are unchanged.

What you'll get

  • App access: auto-lock after idle, lock on screen-off/resume, optional blur in app switcher, passcode + optional app biometric.
  • Data unlock: after wallet password verify, enroll fingerprint/face to skip typing password next time (password always works as fallback).
  • Two settings: independent toggles for app vs data biometrics.
  • Sleep mode: after 10 min background idle, stop chain polling until you return and unlock the app.
  • Android + iOS: Kotlin and Swift native modules; stronger design — secrets never exposed to the WebView.

What stays the same

  • Browser dev and Electron — no biometrics or auto-lock wiring.
  • Exit, Leave room, revoke — unchanged.
  • Wallet + chat still mount together for data unlock.

Out of scope

  • Web/Electron biometrics
  • Re-encrypting wallet under biometrics only
  • Exit / LEAVE ROOM changes
