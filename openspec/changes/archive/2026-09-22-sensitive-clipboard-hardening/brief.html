Sensitive clipboard hardening

TL;DR

Payment IDs, addresses, keys, and similar values can be selected and copied by accident today, and they stay on the clipboard. After this change, those values are not selectable. Copy is a button. iOS drops the paste after 60 seconds. Everywhere else we do not touch the clipboard again unless you tap Clear clipboard in Privacy.

What you'll get

  • Copy buttons write only the raw value — no labels.
  • A Privacy toggle named Clipboard reminder can toast after a sensitive copy (never shows the secret).
  • On Android and desktop, that toast also points you to Clear clipboard.
  • Clear clipboard wipes whatever is on the clipboard. It does not peek first.
  • Seed words stay write-down only (Need more time still works). Spend and view keys each have Copy.

How it works

One copy path writes the value. On iPhone it is marked local and expires in 60 seconds. On Android it is marked sensitive. The app never reads the clipboard on a timer or when you come back to the app, and it does not keep a copy just to compare later. GrapheneOS does not add a short clipboard timeout — we do not rely on the OS one-hour clear.

What changes for you

  • Privacy: Clipboard reminder + Clear clipboard.
  • You cannot highlight a payment ID or address to copy it — use Copy.
  • Seed: still no Copy. Keys: Copy each.

Risks and open questions

  • On web and desktop the value stays until you copy something else or tap Clear clipboard.
  • Clear clipboard will erase a password you just copied in another app if you tap it.
  • iOS expiry needs the phone app’s native clipboard path, not the browser page alone.

Out of scope

  • Auto-clear after 60 seconds on Android, web, or desktop
  • Reading the clipboard to see if it still matches
  • Changing how chat messages or typed fields copy
