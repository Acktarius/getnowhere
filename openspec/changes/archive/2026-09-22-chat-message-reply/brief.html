Chat message reply

TL;DR

When a 1:1 room is online, you can reply to a peer’s live message. The reply is a normal message with a small grey truncated quote of what you answered, above your new text — SimpleX/Keet style, no names needed.

What you'll get

  • Reply arrow in the long-press menu, beside the Edit pencil (only online, only peer live bubbles, not deleted).
  • Grey truncated preview above the composer while you type.
  • Click/tap away from the input cancels the reply.
  • After send, both sides see the grey quote frozen on that bubble.

How it works

Still a normal live text message. We add two optional fields: which message you answered, and a short frozen snapshot of its text. Chain/relay messages never carry reply data. 

flowchart TD
  A[Long-press peer bubble] --> B{Room online?}
  B -->|no| Z[No Reply arrow]
  B -->|yes| C[Tap Reply]
  C --> D[Grey preview above composer]
  D --> E{Stay in input?}
  E -->|leave input| F[Cancel — normal send next]
  E -->|type + Send| G[Live text + snapshot fields]
  G --> H[Bubble: grey quote on top]

What changes for you

  • In an online room: long-press a peer message → Reply → type → Send.
  • Leave the input without sending → reply is cancelled.
  • Offline / own messages / relay / deleted → no Reply.

Risks and open questions

  • Quote is frozen: if they edit or delete later, your quote stays as it was.
  • Truncation length default ~100 characters (can tweak later).
  • Optional dismiss “X” on the composer preview is polish, not required for v1.

Out of scope

  • Reply while offline or on chain/relay messages
  • Replying to your own messages
  • Group chats / “replying to Alice” labels
  • Tap quote to jump to the original
