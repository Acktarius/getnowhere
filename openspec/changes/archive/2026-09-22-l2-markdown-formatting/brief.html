L2 chat markdown-lite

TL;DR

Live Holepunch (L2) chat bubbles render a small markdown subset — bold, italic, strike, inline code, line breaks, and bullets. You still type plain text; relay (chain) messages stay plain. Nothing changes on the wire.

Syntax

  • **bold**, *italic*, ~~strike~~, `code`
  • Two trailing spaces + newline → hard line break
  • * at line start → bullet

Non-goals

  • No formatting on L1 relay bubbles
  • No composer preview while typing
  • No links, headings, or full GFM
