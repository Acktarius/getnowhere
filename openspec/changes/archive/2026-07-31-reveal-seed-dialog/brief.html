Reveal seed in a dialog

TL;DR

In Backup settings, after you enter your passcode and tap Reveal, the seed appears in a dialog so you can copy it somewhere safe for wallet restore. The dialog closes itself unless you ask for more time.

What you'll get

  • Passcode → Reveal seed → dialog with warning text and the words.
  • One primary action: Got it (closes immediately).
  • Need more time slowly appears beside Got it over 30 seconds, then becomes tappable.
  • If you ignore Need more time for 5 seconds after it unlocks, the dialog closes.
  • Tapping Need more time restarts the 30-second fade cycle.

How it works

Same passcode check as today. On success we open a dedicated seed dialog instead of replacing the page with the old backup checklist panel. Closing does not mark the seed as “backed up” yet — that decision is deferred.

What changes for you

  • Seed reveal on Backup settings is a popup, not a full-page second reveal.
  • You will not see the “I stored my seed offline / Confirm backup” checklist on this path.
  • Creating a new wallet (onboarding) still uses the existing seed backup panel.

Risks and open questions

  • The seed stays on screen until you dismiss or the timer closes it — keep the device private while open.
  • We are not recording “backup confirmed” from this dialog yet (to reassess later).

Out of scope

  • Changing onboarding seed backup.
  • Exporting the seed in the metadata JSON download.
  • Marking backup complete from Got it.
