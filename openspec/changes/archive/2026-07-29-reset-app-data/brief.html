Delete wallet & reset app data

Operator brief for change reset-app-data

TL;DR

Settings will get two working danger buttons. Delete wallet clears the wallet and chat/contact state so you can import another wallet, while keeping theme and similar preferences. Reset app data clears wallet state and preferences for a clean slate.

What you'll get

  • A real Delete wallet action (confirm → wipe → reload → Welcome / Import).
  • A real Reset app data action that also drops theme/settings/node prefs.
  • Same behavior in the browser and Electron Alice/Bob windows (each window keeps its own storage).
  • Automated tests that prove prefs survive delete-wallet and disappear on full reset.

How it works

The app removes an explicit list of storage keys (wallet blob, onboarding flag, contacts, rooms, etc.). Full reset also removes preference keys. Memory is cleared first so secrets do not linger after the wipe. Then the page reloads.

What changes for you

  • Open Settings: two red buttons instead of one dead stub.
  • Browser confirm dialog before either wipe.
  • No need to manually clear site data or delete ~/.config/getnowhere-* for a normal wallet swap.

Risks and open questions

  • If a future feature adds a new storage key and forgets to register it, it could survive a wipe — lists are documented and exported for review.
  • Mobile secure-storage bulk wipe is deferred until a native adapter exists; the same Settings buttons will call the same functions.

Out of scope

  • Electron IPC / wiping the whole Chromium profile directory.
  • Typed “type RESET to confirm” dialogs.
  • Multi-wallet switcher (app remains single-wallet).
  • Migrating or exporting data before wipe.
