Nav Exit, leaveRoom, encrypted room history

TL;DR

Exit on the bottom bar will lock the wallet and return to the open screen, while keeping the wallet and chat history encrypted on this device. Leaving a room forever gets a clear name (leaveRoom) and leaves only a tiny “revoked” stub so that room id cannot come back.

What you'll get

  • Bottom nav order: Chats → Contacts → Wallet → Settings → Exit (door).
  • Exit asks Confirm disconnect; cancel does nothing.
  • After Exit, reopen wallet from welcome; conversations still there when Local message retention was on (encrypted with wallet password).
  • One shared confirm dialog for Exit, delete wallet, and reset app data.
  • Revoked rooms keep only { roomId, revoked: true } — no leftover messages.

How it works

While you are unlocked, messages live in memory. On Exit, if Local message retention is on, we write them into the same encrypted wallet store that already holds contacts, then clear keys from memory. If that setting is off, Exit still locks the wallet but does not save chat text. Leave-forever still destroys the live room and sends revoke; the blob keeps a revoked stub so the same id cannot be recreated. 

flowchart LR
  A[Unlocked chat] -->|Exit confirm| B[Flush messages into wallet blob]
  B --> C[Soft-leave P2P topics]
  C --> D[Lock wallet / clear RAM]
  D --> E[Welcome / open]
  E -->|Unlock| F[Hydrate messages from blob]
  A -->|Leave forever| G["Tombstone: roomId + revoked"]

What changes for you

  • Use Exit to lock and leave the session (not Leave room).
  • Leave room still means gone forever + revoke to the peer.
  • Settings destructive actions use the same style of confirm dialog.

Risks and open questions

  • History is on this device’s storage (localStorage under Electron/browser). Uninstall without a backup still loses it.
  • Catching up missing messages from the other peer is a later change.
  • Very long chats will grow the encrypted wallet blob.

Out of scope

  • Peer-to-peer history catch-up.
  • Full shared replication (Hypercore-style).
  • A second plaintext copy of transcripts outside the wallet blob.

Work overview

  • ConfirmModal + Settings confirms (2 tasks)
  • leaveRoom rename + nav Exit (2 tasks)
  • Wallet-blob transcripts + revoke tombstone + docs/e2e (3 tasks)
