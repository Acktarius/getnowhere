Redact Room Diagnostics

Change brief — generated for operator approval

TL;DR

The room diagnostics sheet today shows the full raw room ID (and lets you copy it). The room ID is a protocol capability secret, so exposing it in plain text is a mild but real risk (screenshots, shared screens, DOM readers). After this change the sheet shows a short human-readable label like aabb…cd instead — still useful for verbally confirming which room you're both in, but no longer the full capability value.

What you'll get

  • The diagnostics sheet "Room id" row shows a truncated label, e.g. aabb…cd, not the full hex string.
  • The copy button next to "Room id" copies that truncated label — same behavior, safer value.
  • The "Topic" row is unchanged: already shows a short non-copyable excerpt, stays that way.
  • Both the loading-state sheet and the fully-loaded sheet are updated consistently.

How it works

A new shortRoomId(id) helper is added next to the existing shortTopicRef in the format utilities. For the current 4-byte (8-hex) room id format it produces head4 + "…" + tail2. The two call sites in ChatRoomScreen are updated to pass the truncated string as the CopyButton value and as the display text. The full raw id is never passed into the sheet component.

What changes for you

  • Diagnostics sheet: room id row now reads e.g. aabb…cd instead of aabbccdd.
  • Copying the room id copies the short label — usable for verbal peer comparison, not for protocol re-entry.
  • No UI flow, no settings, no wallet/data changes.

Risks and open questions

  • Weak concealment: A 4-byte id is only 32 bits — truncation is defense-in-depth, not a strong secret. Full ids remain in memory, routing, and persistence. This change removes the clean copy-paste exposure path only.
  • Not addressed here: full room id in the URL hash (/chats/:roomId) is a separate finding tracked elsewhere.

Out of scope

  • Gating the whole diagnostics sheet behind a dev/debug flag.
  • Changes to route params, persistence, chat store, or bridge.
  • Topic ref display changes (already truncated and non-copyable).
